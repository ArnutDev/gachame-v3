Auto Update System Checklist

บันทึกขั้นตอนการพัฒนาระบบและการตั้งค่าก่อนเริ่มรันงานจริง

📋 Things to Do (ขั้นตอนที่เหลือหลัง Push ขึ้น Git)

รวมโค้ดเข้าสู่สายหลัก (Merge Pull Request)

รวมกิ่ง feat/auto-update เข้าสู่กิ่ง main ใน GitHub เพื่อเปิดสิทธิ์การใช้งานเมนูสั่งรัน Actions (Manual Trigger)

สร้างและตั้งค่า Secret ตัวแปร IMAGE_REPO_PAT

นำรหัส Personal Access Token (PAT) ไปตั้งค่าไว้ใน Repository หลัก -> Settings -> Secrets and variables -> Actions โดยตั้งชื่อตัวแปรว่า IMAGE_REPO_PAT

ปรับปรุงชื่อ Repository รูปภาพปลายทาง

ตรวจสอบไฟล์ .github/workflows/auto-update.yml บรรทัดที่ 75 ปรับแก้จาก gachame/images เป็น Username และชื่อ Repo ปลายทางจริงของคุณ

อัปเดตไฟล์ข้อมูลนำเข้าประจำเดือน (Rangers/Gears Input)

เมื่อขึ้นรอบเดือนใหม่ ให้นำรายชื่อเรนเจอร์/เกียร์มาใส่ใน tools/inputs/rangers.txt และ tools/inputs/gear.txt โดยใช้สัญลักษณ์ KEEP| หรือ TEMP| นำหน้า

สั่งรันการอัปเดตข้อมูล (Run GitHub Actions)

ไปที่ Actions -> เลือก Auto Update Game Data -> กดปุ่ม Run workflow เพื่อเริ่มกระบวนการดึงข้อมูลและอัปโหลดรูปภาพทั้งหมด

✅ Completed Tasks (ขั้นตอนที่ดำเนินการเสร็จสิ้นแล้ว)

เขียนสคริปต์หลักและระบบคัดแยกข้อมูล (Ranger & Gear Parser)

เขียนพัฒนาไฟล์ tools/update.py คัดแยกร่างปกติ/อัลตร้า และแบ่งเกียร์ตามระดับดาวอัตโนมัติสำเร็จ

ระบบส่งเรนเจอร์เข้า Base Database อัตโนมัติ (Base Promotion)

ตั้งระบบอ่านจับคู่เรนเจอร์ในเดือนคู่ เพื่อดึงตัวที่ระบุว่า KEEP ของเดือนคี่ก่อนหน้ามาเขียนลง Base Database หลักสำเร็จ

ระบบเขียน Changelog บันทึกการอัปเดต (updates.json Engine)

ระบบจะปัดเศษเวอร์ชันขึ้นทีละ 1 Minor และลงประวัติตามเวลาไทย (UTC+7) อัตโนมัติสำเร็จ

ระบบคลาวด์การประมวลผล (GitHub Actions Workflow)

สร้างไฟล์การตั้งค่า .github/workflows/auto-update.yml พร้อมติดตั้งเบราว์เซอร์ Headless บนคลาวด์สำเร็จ

ตั้งค่าและสร้างโครงสร้างคลังรูปภาพปลายทาง (Images Sync Target)

ปรับแก้สคริปต์ Sync ให้แยกไฟล์รูปภาพส่งไปจัดเก็บแยกเป็นสัดส่วนที่โฟลเดอร์ images/rangers และ images/gears สำเร็จ
