บันทึกสรุปการติดตั้ง Data Loading & Validation Utilities

ได้ทำการติดตั้งฟังก์ชันยูทิลิตี้สำหรับโหลดและตรวจสอบความถูกต้องของโครงสร้างไฟล์ JSON ข้อมูลเกม (Rangers & Gears) ตามข้อกำหนดใน docs/json-schema.md ปราศจากขั้นตอนการสุ่มใดๆ เรียบร้อยแล้ว รายละเอียดมีดังนี้:

1. ยูทิลิตี้ดาวน์โหลดและตรวจสอบข้อมูล (DataLoader Utility)

เขียนไว้ในไฟล์ src/services/dataLoader.ts โดยรองรับการโหลดข้อมูลแบบ dynamic:

  • validateRangerRaw & validateGearRaw: ทำหน้าที่ตรวจสอบว่าข้อมูล JSON เป็น Array, อ็อบเจกต์ภายในไม่มีฟิลด์ที่ว่างเปล่า (Name, Image, UnitCode/ItemCode) และไม่มีรหัสไอดีที่ซ้ำซ้อนกันในชุดข้อมูล
  • loadBaseRangers & loadBaseGears: โหลดข้อมูลถาวรเริ่มต้น (Base Data) จากโฟลเดอร์ src/data/ โดยอ้างอิงระดับความหายาก (Rarity)
  • loadEventRangers & loadEventGears: โหลดข้อมูลเฉพาะช่วงเวลาอีเวนต์ (Event Data) จากโฟลเดอร์ตามรูปแบบ events/YYYY-MM/
  • loadCombinedRangers & loadCombinedGears: ประมวลผลและรวมชุดข้อมูล Base Data เข้ากับ Event Data เพื่อสร้างข้อมูลสำเร็จรูปสำหรับนำไปประยุกต์ใช้ในตู้สุ่มและ UI

2. ไฟล์ข้อมูล JSON จำลองที่สร้างขึ้น (Mock JSON Data Files)

สร้างโครงสร้างไฟล์ตามมาตรฐานเพื่อให้ระบบโหลดไปใช้งานและพร้อมทดสอบ:

src/data/rangers/7-normal.json, 7-ultra.json, 8-normal.json, 8-ultra.json
src/data/gears/5.json, 6.json, 7.json, 8.json, 9.json
src/data/events/2026-08/rangers/8-normal.json, 8-ultra.json
src/data/events/2026-08/gears/9.json
