เสร็จสิ้นภารกิจ

บันทึกสรุปการจัดทำระบบ Routing ใน GachaMe

ได้ทำการติดตั้งระบบการนำทาง (Routing) โดยใช้ react-router-dom และสร้างหน้าว่างของแต่ละเพจเรียบร้อยแล้ว รายละเอียดมีดังนี้:

1. หน้าเพจเริ่มต้นที่ถูกสร้างขึ้น (Placeholder Pages)

สร้าง Component เปล่าสำหรับแสดงผลเฉพาะหัวข้อของหน้าเพจ (Page Title) ภายใต้ src/pages/:

  • Home.tsx: หน้าแรกแสดงผล "Home"
  • RangerGacha.tsx: หน้าสำหรับสุ่มเรนเจอร์แสดงผล "Ranger Gacha"
  • GearGacha.tsx: หน้าสำหรับสุ่มอุปกรณ์แสดงผล "Gear Gacha"
  • Collection.tsx: หน้าแสดงสมุดสะสมไอเทมแสดงผล "Collection"
  • Statistics.tsx: หน้าแสดงสถิติการสุ่มแสดงผล "Statistics"
  • Settings.tsx: หน้าตั้งค่าระบบจำลองแสดงผล "Settings"

2. การตั้งค่าระบบ Routing และเมนูนำทาง

  • อัปเดตไฟล์ src/main.tsx เพื่อกำหนด BrowserRouter, Routes และ Route
  • สร้าง Layout หลักที่มีเมนูนำทาง (Navigation Bar) ซึ่งใช้ NavLink ช่วยให้กดเปลี่ยนหน้าต่างๆ และดึงเนื้อหามาแสดงผลผ่าน Outlet ได้ทันที

3. การตรวจสอบความถูกต้อง

  • ทดสอบการคอมไพล์ซอร์สโค้ดและบิลด์โปรเจกต์ผ่านคำสั่ง npm run build พบว่าไม่มีข้อผิดพลาดทางด้าน TypeScript หรือ Vite
