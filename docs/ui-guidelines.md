# UI Guidelines

## Goals

Modern

Fast

Responsive

Simple

---

# Responsive

Support:

Desktop

Tablet

Mobile

---

# Components

Components should be:

- reusable
- composable
- small
- independent

---

# Loading

Every async action should have:

- Loading state
- Empty state
- Error state

---

# Animations

Animations should be lightweight.

Avoid unnecessary motion.

---

# Accessibility

Use semantic HTML.

Support keyboard navigation.

Provide alt text for images.

---

# Performance

Lazy load pages.

Optimize images.

Avoid unnecessary rerenders.

Prefer memoization only when beneficial.
